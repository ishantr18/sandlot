## Disclosure statement (draft — paste into the submission)

Diamond Drive was built with AI assistance, disclosed in full here.

**AI inside the app:** two pretrained Google MediaPipe computer-vision models — BlazePose (Pose Landmarker, lite) for 33 body landmarks per frame and BlazeFace (short-range) for face detection — both Apache 2.0, self-hosted, and run on the user's device via WebAssembly. Neither model was trained or fine-tuned by me; both are used as off-the-shelf perception. **No large language model runs in the app.** Everything built on top of the landmarks — the quality gate, swing detection, the seven biomechanical metrics, the findings engine, the three-stage anonymization pipeline, and the whole trust and safety layer — is original code.

**AI as a development tool:** I used Claude Code throughout as a pair programmer, tutor, and reviewer. It wrote scaffolding, plumbing, and substantial portions of the application code from my specifications; I directed the architecture, designed the privacy and trust models, filmed and ran every calibration clip, found the engine's real-world failures by testing against swings I understand as a player, and decided how each was fixed. The table above logs each session. AI did not constitute the entirety of the technical development, and I can explain and defend any file in this repository.
