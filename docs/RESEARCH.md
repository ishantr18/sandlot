# Research — Rules, Criteria, District Analysis

## Official 2026 rules (from the CAC rulebook PDF)
- **Deadline:** Mon, Oct 26, 2026, 12:00 pm EDT. Submissions cannot be modified after.
- **Eligibility:** middle/high school student on Oct 26; compete where you live OR attend school; one entry per person per year; teams up to 4.
- **App age:** must be created after Oct 30, 2025.
- **Platform/language:** anything (web, mobile, robots, AR/VR, wearables; any language).
- **Originality:** all coding by the student(s); open-source libraries OK but must be documented; project must reflect significant personal effort and technical understanding.
- **AI usage:** permitted, but ALL AI use must be fully disclosed in submission materials; AI must not constitute the entirety of technical development. → keep `AI_USAGE_LOG.md` current daily.
- **Judges may request source code** to verify functionality; refusal = disqualification.

## Judging criteria (exact wording)
1. Quality of the idea (creativity and originality)
2. Implementation of the idea (user experience and design)
3. Demonstrated excellence of coding and programming skills

## Demo video (the primary judged artifact)
1–3 min, public YouTube/Vimeo. Must include: participant names, app name, purpose in ONE clear sentence, target audience, tools/languages used, functionality showcase. Over-time videos may be penalized.

## Submission questions (prepare written answers)
1. Title  2. Purpose  3. Inspiration  4. Technical difficulty faced + how solved  5. Biggest takeaway  6. What you'd change in a 2.0 version

## WA-01 analysis (Rep. Suzan DelBene — ex-Microsoft VP, House data-privacy leader)
| Year | Winner | School | App |
|---|---|---|---|
| 2023 | ViziBox | The Overlake School (Redmond) | Reads aloud hard-to-read documents (accessibility) |
| 2024 | Read Buddy for Neurodivergent | Lake Washington HS (Kirkland) | Reading aid for neurodivergent users |
| 2025 | AnemoDx | Redmond High School | Non-invasive anemia screening for underserved communities |

Pattern: all access-equity apps; all technically substantial; all from the Redmond–Kirkland corridor. DelBene hosts an App-A-Thon (~Oct) — attend if held.

**WA-02 option (Larsen/Everett):** far lower bar (2025 winner: middle-school immune-system game). Mill Creek residence = WA-01, but if school address is in WA-02, competing there is allowed. Check school's 9-digit zip before registering.

## National context (what top apps look like)
2025 national winner BoostT1D (T1D assistant: AI food-photo carb estimation + Nightscout integration + buddy/mentor community). Other top winners: VERDIS (drone + CNN crop disease), OptiSense (optical glucose sensor), Computerpreter (ASL, LSTM), RoadWatch (Raspberry Pi pothole detection), CoFIS (flood-risk maps from NOAA/USGS/FEMA data).
Takeaways: AI/ML is table stakes used deeply, hardware/real-data integration stands out, personal stories win, cost/equity framing recurs.
