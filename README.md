# CAC 2026 — Diamond Drive

Entry for the 2026 Congressional App Challenge, Washington's 1st District (Rep. Suzan DelBene).
**Submission deadline: Monday, Oct 26, 2026, 12:00 pm EDT. Target: submit week of Oct 12.**

## One-sentence purpose
An AI baseball coach that gives underprivileged kids pro-level swing analysis on any phone — with privacy engineered in (on-device face blurring) and a supervised volunteer-mentor layer on top.
